# P2PDiag Documentation

P2PDiag is a .NET 10 interactive console diagnostic tool designed to investigate LAN and peer-to-peer communication problems.

## Documentation map

- architecture.md — project structure, layer responsibilities and feature-aggregate organization.
- features.md — functional scope and diagnostic capabilities.
- usage.md — installation, startup and interactive CLI usage.
- localization.md — resource files, cultures and user-facing message rules.
- diagnostics.md — diagnostic layers, evidence and interpretation.
- dynamic-monitoring.md — long-running monitors, progress rendering and cancellation.
- reports.md — diagnostic sessions, reports and endpoint comparison.

The GitHub feature source of truth is issue #1: [FEATURE] P2P Diagnosis Tool.

Implementation is divided into five phases represented by task issues #2 through #6.
